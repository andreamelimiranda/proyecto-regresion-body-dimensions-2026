# App Seber & Lee - Capítulo 1

Aplicación didáctica para estudiar el capítulo 1 de **Linear Regression Analysis** de Seber & Lee, enfocada en:

- Vectores de variables aleatorias.
- Esperanza de matrices aleatorias.
- Matrices de covarianza.
- Teoremas 1.1 a 1.6.
- Demostraciones paso a paso.
- Flashcards, quiz y calculadora simple.

La app no contiene PDFs ni archivos pesados. Todo está en un único `index.html`.
